# Video Campuran Warna — Tahun 5

Animasi Bahasa Melayu selama 3 minit tentang campuran cat warna primer kepada warna sekunder, dengan sari kata, narasi dan kuiz ringkas.

[**Muat turun video MP4 untuk telefon (6.4 MB)**](https://github.com/jhp9gd7cyz-netizen/Percubaan/raw/refs/heads/main/Campuran_Warna_Tahun_5_Telefon.mp4)

Selepas dimuat turun, buka video melalui Galeri, Photos atau pemain video telefon. Putar telefon melintang untuk paparan lebih jelas.

Jika pautan meminta log masuk, gunakan akaun GitHub yang mempunyai akses kepada repositori ini. Pada halaman fail video, tekan **Download raw file** untuk menyimpan MP4.

Video menunjukkan campuran cat: merah + kuning = jingga; kuning + biru = hijau; biru + merah = ungu. Narasi menggunakan suara sintetik Bahasa Melayu dengan variasi nada, kelajuan dan jeda.
